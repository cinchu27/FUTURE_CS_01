# Vulnerability Assessment Report – OWASP Mutillidae

## 📌 Overview
This repository contains a **Vulnerability Assessment Report** conducted in a controlled lab environment against **OWASP Mutillidae**, a deliberately vulnerable web application. The goal of this project was to identify common web application security flaws, assess their risk using **CVSS v3.1**, and recommend appropriate remediation strategies.

This project is intended for **learning, academic, and ethical security testing purposes only**.

---

## 🧪 Lab Setup
- **Attacker Machine:** Kali Linux  
- **Web Application:** Mutillidae  

---

## 🛠 Tools Used
- **Nmap** – Network scanning and service enumeration  
- **OWASP ZAP** – Web application vulnerability scanning  
- **Kali Linux** – Penetration testing environment  
- **Canva** – Report design and visualization  

---

## 📂 Scope
- Testing was strictly limited to a **local lab environment**
- No production or external systems were targeted
- All activities followed ethical security testing practices

---

## 🚨 Identified Vulnerabilities

### 1️⃣ SQL Injection (MySQL)
### 2️⃣ Reflected Cross-Site Scripting (XSS)
### 3️⃣ Path Traversal
